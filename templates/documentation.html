GitaBot Documentation

Introduction

GitaBot is an AI-powered chatbot designed to provide guidance and wisdom derived from the sacred teachings of the Bhagavad Gita. By leveraging natural language processing, sentiment analysis, and the Google Cloud Translation API, GitaBot offers personalized responses that reflect the spiritual and philosophical principles of the Gita. Whether you seek advice on personal matters, philosophical insights, or a deeper understanding of the Gita's teachings, GitaBot is here to assist, making the timeless wisdom of the Bhagavad Gita accessible to all, including Hindi speakers.

Features

  • Interactive Chatbot: Engage in real-time, meaningful dialogues with GitaBot, which draws from the Bhagavad Gita to offer advice, clarity, and insights into your queries. GitaBot is designed to respond in a manner consistent with the teachings of Lord Krishna, providing users with guidance that is both relevant and spiritually enriching.
  • Sentiment Analysis: GitaBot analyzes the emotional tone of your queries using VADER (Valence Aware Dictionary and sEntiment Reasoner) from NLTK. This analysis helps in tailoring responses that resonate with your current emotional state, ensuring that the guidance provided is compassionate and appropriate.
  • Sentiment-Based Guidance: Building on the sentiment analysis, GitaBot offers responses that are adapted to the emotional context of the conversation. For example, if a user expresses anxiety or stress, GitaBot may offer calming advice or suggest meditation practices as outlined in the Gita.
  • Multilingual Support: GitaBot supports English and Hindi. Queries and responses can be translated between languages using the Google Cloud Translation API, preserving markdown structure where applicable.
  • Visually Appealing Interface: Designed with a user-friendly and aesthetically pleasing interface, GitaBot ensures a seamless and enjoyable user experience. The interface is built using HTML, CSS, Bootstrap, and JavaScript.
  • Gita Dataset Lookups: GitaBot can retrieve specific shlokas, Hindi meanings, and English meanings from the Bhagavad Gita dataset (Bhagwad_Gita.csv) based on identified verse IDs.

How It Works

  • User sends a query in English or Hindi.
  • If the query is in Hindi, it is translated to English using Google Cloud Translation.
  • VADER sentiment analysis determines the emotional tone (Positive, Negative, or Neutral).
  • Groq API (openai/gpt-oss-120b) generates a response based on the query and sentiment.
  • If applicable, the most relevant Bhagavad Gita shloka is identified and its details (shloka, Hindi meaning, English meaning) are fetched from the dataset.
  • Sentiment-based short messages and learning messages are generated.
  • The final response is sent back to the user in their original language.

Usage

GitaBot is designed to be intuitive and easy to use. Users can type their questions or concerns into the chat interface. The sentiment analysis feature is automatically activated with each query, providing an additional layer of personalization to the interaction. Users can switch between English and Hindi using the language selector.

Applications

GitaBot has broad applications, making it a valuable tool for anyone interested in personal development, spiritual growth, or simply learning more about the Bhagavad Gita. Some potential applications include:

  • Self-Reflection and Growth: Individuals can use GitaBot as a tool for self-reflection, seeking advice on how to handle life's challenges or how to cultivate virtues such as patience, compassion, and resilience.
  • Educational Resource: GitaBot can serve as an educational resource for students and scholars of the Bhagavad Gita, offering explanations of key concepts and answering questions about the text's teachings.
  • Spiritual Companion: For those on a spiritual journey, GitaBot can act as a companion, providing daily guidance and inspiration drawn from the Gita's teachings.
